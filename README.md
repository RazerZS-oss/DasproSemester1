## 🛠️ Cara Kompilasi & Menjalankan

### Menggunakan Compiler GCC / G++:
```bash
# Contoh kompilasi tugas pertemuan 17
cd Pertemuan17_PDP
g++ main.cpp -o program_pdp
./program_pdp
```

### Menggunakan Code::Blocks IDE:
1. Buka aplikasi **Code::Blocks**.
2. Pilih menu **File > Open**, lalu buka file proyek `Tugas_PDP.cbp`.
3. Klik tombol **Build and Run (F9)**.
